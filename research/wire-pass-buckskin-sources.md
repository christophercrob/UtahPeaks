# Wire Pass & Buckskin Gulch route sources

- **BLM — Wire Pass:** https://www.blm.gov/visit/wire-pass
  - Wire Pass Trailhead to the Buckskin Gulch confluence: approximately **1.7 miles one way**.
  - Access: House Rock Valley Road, 8.3 miles south of US-89 from the Kanab direction.
- **OpenStreetMap API reference geometry:** https://api.openstreetmap.org/api/0.6/map?bbox=-112.0500,36.8500,-111.8000,37.1000
  - Used solely to trace a simplified visual reference line for the full mapped Buckskin Gulch corridor in the app.
  - The full Buckskin Gulch path segment measures approximately **17.37 miles** in the retrieved geometry.

The site display rounds this to **17+ miles** and labels Wire Pass separately as **1.7 miles one way**.
